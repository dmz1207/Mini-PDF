# Mini PDF 0.5 验证记录

验证环境：Windows 10 家庭中文版 x64，10.0.19045；系统自带 .NET Framework。
Windows 11 使用相同 API，但没有独立 Windows 11 实机验证。

本次通过：210 项程序回归、33 项独立 PDF 校验、12 项单文件启动器检查，合计 255 项。

## 本版新增验证

- 默认英文，English 第一、简体中文第二；检查全部默认菜单及子菜单均有英文。
- 英中即时切换，保留原生文档句柄、当前页、精确缩放、滚动、编辑工具、线宽、未保存修改和撤销。
- 文件名、搜索输入、PDF 原文与中文编辑内容不被界面翻译。
- 右键菜单与编辑对话框双语，英文 Auto 字体选项仍可正确写入中文。
- 英文、中文帮助菜单实际打开相应内置说明；英文未保存提示可取消关闭。
- 反复语言切换检查 GDI 资源，不创建语言配置缓存。

- 标签与菜单同排，阅读工具栏在下一行；单文档隐藏标签行，菜单回到主工具栏。
- 菜单图标和点击范围加大，顶部文字和常用图标放大，行高继续保持紧凑。
- 实际 Windows 鼠标消息拖动标签向左、向右排序，键盘切换遵循新顺序。
- 拖动保留当前文档、页码、精确缩放、滚动位置、未保存修改和撤销记录。
- 小幅鼠标移动、Esc、鼠标捕获丢失、行外释放，不意外关闭文档。
- 十个标签时在两端停留可连续滚动排序；原文件撤销历史仍可用。
- 排序后的关闭按钮、中键关闭、F10、阅读模式恢复；反复切换菜单位置检查 GDI 资源。

## 现有功能回归

- 多文件原生标签；正文只渲染选中标签的页面，不混合不同 PDF。
- 各标签独立保留页码、精确缩放、旋转、布局、滚动位置、编辑工具及撤销历史。
- Ctrl+Tab / Ctrl+Shift+Tab、关闭最后标签后重开、重复打开同一路径。
- 实际保存提示的取消与放弃；关闭窗口检查非当前标签的未保存内容。
- 独立适宽按钮实际点击执行；菜单与 Ctrl+2 保持可用。
- Ctrl+6 自动单页整页，Ctrl+7 自动双页适宽；不同尺寸页面和奇数末页。
- 单页适宽忽略其他页的不同纸张尺寸；多个奇偶窗口宽度及侧栏开关均不重复扣除滚动条宽度。
- 适宽左右留白 0–1 像素（双页四舍五入最多 2 像素）；侧栏隐藏不再占用整条宽度。
- 约 10 像素的 Windows 原生滚动条；200 页文档可滚到超过 65535 像素的末尾，鼠标滚轮正常。
- 阅读模式切换标签并恢复编辑工具；反复标签切换检查 GDI 资源。
- 再次启动把文件转入已有窗口；中文和空格路径、相对路径、多参数打开、显式新窗口。
- 文件转交后清理解包目录；异常结束后可重新取得单实例所有权。

## 程序回归

- 默认单行紧凑工具栏、菜单反复展开；阅读模式保留原生标题栏、关闭按钮和窗口位置。
- 1%–6400% 缩放，四个旋转方向的分块图像与整页裁剪逐像素相同，高倍缩放显示实际矢量文字并限制缓存。
- 四种双层 PDF：隐藏 OCR、图像覆盖 OCR、透明文字和组合对象内 OCR；搜索、选择及顶层 OCR 修改。
- 独立渲染确认修改 OCR 后页面像素不变，没有新增重影，扫描图像像素保持不变。

- 真实窗口启动；原生右键菜单反复打开和关闭，修复提前释放 ContextMenuStrip 的异常。
- 修复 PageUp/PageDown 被误设为菜单快捷键导致的启动异常。
- 真实鼠标选择文字、拖动图片、绘制矩形和手写，通过真实对话框添加中文。
- 原文字替换、中文和空格、字体缺字提示、图片移动缩放、批注增删改、保存后重新打开。
- 修复 GDI+ 图像复制仍引用已释放原生缓冲区，导致导出图像时崩溃的问题。
- 修复部分系统字体的 TTC 和 Unicode 映射；新增字体子集化后重载文档。
- 单页、双页、书籍、连续、网格布局，双页整组翻页，书籍封面居中，多页正确定位。
- 缩放增减网格列数、精确整数/小数百分比、输入框 Ctrl+A、非法输入，1% 和 6400% 边界。
- 四种视图旋转方向的编辑坐标；视图旋转不修改 PDF。
- 缩放保留连续文档当前位置，编辑保留当前页的滚动位置。
- 全屏、幻灯片、阅读模式进入退出；隐藏所有界面后仍可右键退出并恢复原布局。
- 侧栏边缘按钮收起、重新打开、反复切换；阅读模式隐藏按钮，退出恢复之前的侧栏状态。
- 增删、复制、旋转、移动、提取、合并页面；提取顺序、最后一页保护。
- 正确/错误密码、中文 AES-256 密码、用户/所有者权限、加密保存。
- 保存失败不覆盖原文件、不清除未保存状态；撤销/重做恢复保存状态。
- 200 页文档打开和网格显示，限制窗口外页面渲染和图像缓存。
- 反复布局切换检查 GDI 资源数量；打印经预览控制器校验页码范围，不发送实体打印任务。

## 独立 PDF 校验

使用 ReportLab 生成外部文档；pypdf 检查保存结果；MuPDF 再次渲染。
验证原文字确实替换、中英文及普通空格正确、图片仍为图像对象、标准批注类型和内容存在。
验证提取顺序、页树、保留既有目录、未修改的表单字段值和外观、保留密码保护。
保存后的页面已进行图像检查。

## 单文件启动器

隔离目录只复制一个 EXE：正常启动、带空格的中文文件路径、多实例并行、退出清理、遗留目录清理。
额外验证运行目录里用户自己创建的文件不会被自动清理误删。
修复新文档默认保存位置可能落入临时运行目录的问题。
正式发布包排除测试代码，回归工具引用相同正式程序集。
LZMS 资源压缩后使用 SHA-256 校验解压结果；最终单 EXE 经独立目录启动检查。

## 发布体积

最终 EXE：2,951,168 字节，约 2.81 MiB。
v0.4 为 2,940,928 字节；本次增加 10 KiB。
上一版 GZip 单文件：3,958,784 字节；本次减少约 26%。
比较 Windows MSZIP、XPRESS、XPRESS Huffman、LZMS；最终选用 LZMS、8 MiB 分块。
压缩后内容逐字节等价（构建工具使用 SHA-256 比较），不删减 PDF 引擎功能。
测试代码、开发压缩工具、调试符号不进入发布包；源码保持可维护。
