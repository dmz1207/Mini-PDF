# Mini PDF 0.7.1 — Test record / 测试记录

English summary first; Chinese details follow.

## Verified release

- Environment: Windows 10 Home Chinese x64, build 19045; system .NET Framework 4.x.
- Windows 11 targets the same APIs but has not been tested on a separate machine.
- Program regressions: **392 passed**.
- Independent PDF preservation checks: **33 passed**.
- Independent watermark/merge/signature checks: **51 passed**.
- Independent visible-signature/external-watermark fix checks: **23 passed**.
- Final single-EXE launcher and cleanup checks: **14 passed**.
- Total: **513 checks passed**. Printing used preview controllers; no physical print jobs were sent.
- Final EXE: **3,004,416 bytes (2.8652 MiB)**, version **0.7.1.0**.
- SHA-256: **E514E0A36544802BACE80913AED835F6D8A4FD4B51F7B13EE4F95335C42818CA**.
- Relative to v0.6.1 (2,955,264 bytes), this adds 49,152 bytes while retaining the same PDFium engine.
- LZMS compression is verified by a SHA-256 round trip. Tests/build tools and fixture certificates are excluded from the application.

## v0.7.1 user-flow coverage

Fifty new program checks cover live Chinese/Latin name entry, switching from imported artwork back to a typed name, physical width and responsive preview, high-resolution name output, full-image fitting, the actual signature menu and confirmation button, single-click placement, automatic object selection, corner resizing with preserved proportions, a real right-click percentage dialog, rotated views, reselecting a signature over body text, drag placement and Esc cancellation.

Third-party fixtures are generated independently with ReportLab and pypdf. Native UI checks exercise checking candidates and the range-matching button. Content/style/position matching removes external text, image, Form and stamp objects, while body text with identical wording and an image at another position are retained. Before/after preview does not edit the original; the whole batch has undo/redo. MuPDF rendering and pypdf parsing independently verify 23 output conditions. The checked-list display was inspected at 150% Windows scaling.

| Feature | Verified scope | Remaining practical limits |
| --- | --- | --- |
| Reading / zoom / tabs | Native mouse/key operations, layouts, exact percentages, title geometry and window modes | Separate Windows 11 machine pending |
| Text / image editing | Save/reopen, Chinese fonts, move/resize/delete, OCR-layer preservation and rollback | Arbitrary font/layout PDFs are not exhaustively covered |
| Annotations / colors | Standard markup persistence, selected-text colors, notes and deletion/undo | Native color-picker internals delegated to Windows |
| Page management / merge | Reorder, duplicates, removal, rotations, page targets, cross-file moves, GUI thumbnail drag | All possible imported document structures are not covered |

Test counts describe these cases, not exhaustive validation of every menu on every PDF or a guarantee of zero defects. The previous signature coverage omitted the complete typed-name placement workflow; this version explicitly adds it.

## Existing feature coverage

- Physical print geometry: exact actual/custom sizes, fit respecting asymmetric hardware margins, shrink-only, orientation, non-contiguous ranges, odd/even/reverse.
- 2/4/6/9/16-up, booklet fold order, padding, right binding, front/back subsets, poster overlap and tile ordering.
- Native vector print output: enhanced-metafile inspection found 315 vector drawing records for the colored fixture. Pixel comparison with source rendering verified placement, scale and colors. High-resolution image fallback also produced a preview.
- Existing AcroForm appearance text is included in printable content, even with ordinary annotations excluded, and the original form/document stays intact.
- Printing UI displays a real current-document preview. All three new signature/watermark/certificate windows expose English controls.
- Batched watermarks on mixed/rotated pages: tagged objects, active-page restoration, page counters, Chinese tiling, background/text/image, replace/remove and single-step undo/redo.
- Actual left-mouse signature strokes export a tightly cropped transparent image; visible signatures persist as PDF image objects.
- Ephemeral test PFX loading, SHA-256 detached signatures on regular PDFs, existing AcroForms and object-stream input.
- Cryptographic integrity distinguished from untrusted self-signed certificates; signed read-only editing protection and byte-identical Save As.
- One-byte tamper detection, appended bytes flagged as later unverified content, and expired/public-only signing certificates rejected.
- Independent pypdf parsing and OpenSSL detached CMS verification for all three signed fixtures, including byte ranges, zero padding, certificate extraction and retained existing form values.
- Combine file-group/page moves, cross-file ordering, rotations, undo and new-document output preserving originals. Native mouse messages exercise thumbnail reordering.
- Page organizer retains destinations/bookmarks attached to surviving pages, keeps the active page, supports duplicates/removal and commits one undoable edit. Multi-page cross-group movement preserves selection order.
- Selected text becomes a standard highlight annotation; save/reopen/undo and twelve-color/custom context palette checked.
- Native left-button hand panning in both axes, temporary Space panning and visible Select/Hand button states. V, H and Esc switch tools as documented.

## Existing regression coverage

Compact title rows in normal/maximized/restored windows; only one minimize/maximize/close set; native move/resize and reading-mode caption restoration. Rounded tabs follow the pointer continuously, cross multiple positions, reverse direction, cancel with Esc, handle capture loss and edge-scroll overflow. Reorder retains document state, zoom, scroll, unsaved edits and undo. File-open forwarding, independent windows and unsaved-close prompts remain covered.

Single/double/book/grid/continuous layouts, fit-width gutters, exact 1%–6400% zoom, bounded high-zoom tiles, sidebar toggles, reading/full-screen/presentation transitions. Existing text/object edits, Chinese subset fonts, markup types, annotation editing/removal, extraction/merge/page trees, bookmarks, mixed dimensions, encryption, permissions, save failure rollback and independently rendered scan/OCR pixels.

English-first menus and nested commands, live Chinese/English switches preserving native document handles/content/reading state, actual embedded guides, localized dialogs, and repeated switches with bounded GDI use. Final portable EXE launches without adjacent DLLs and cleans its own runtime files after normal/abnormal exit while preserving active-instance and user-created files.

## Reproduce

Use a complete source checkout, the system x64 Framework C# compiler, development Python packages pypdf/reportlab/pymupdf/cryptography and OpenSSL:

~~~powershell
python .\源码\verify_pdf.py fixtures .\work\tests
python .\源码\verify_features.py fixtures .\work\tests
python .\源码\verify_fixes.py fixtures .\work\tests
powershell -ExecutionPolicy Bypass -File .\源码\build.ps1 -Test
python .\源码\verify_pdf.py verify .\work\tests
python .\源码\verify_features.py verify .\work\tests
python .\源码\verify_fixes.py verify .\work\tests
powershell -ExecutionPolicy Bypass -File .\源码\test-launcher.ps1
~~~

The program runner skips external-fixture coverage explicitly if fixtures are missing; the counts above use both fixture generators. Test PFX/private keys are generated only in work/tests, are never installed, and are not redistributed. Build/test caches remain in work and are removed from the delivered folder.

## 中文验证说明

本次补充了 50 项程序检查和 23 项独立输出检查，覆盖真实姓名输入、确认、单击放置、毫米尺寸、图片预览缩放、角点及右键百分比缩放、覆盖正文后的重新选择，以及外部水印窗口的勾选和跨页匹配按钮。上一轮没有覆盖完整的姓名签名操作链，本次已针对这个漏项补测。上表列明各类功能实际覆盖范围；未声称穷尽全部 PDF、硬件或驱动场景。

本版共通过 513 项检查：392 项程序回归、33 项独立 PDF 检查、51 项新增功能独立检查、23 项本次签名/外部水印独立检查、14 项最终单 EXE 启动与清理检查。实测 Windows 10 x64 19045，Windows 11 尚需另机测试。打印测试未向实体打印机发送任务。

打印默认直接使用 PDFium 的 Windows EMF/GDI 输出，测试确认存在矢量记录，且位置、比例与颜色同源文档一致。修复了表单打印副本准备后需要重新加载页面外观的问题；原文档、表单字段不被平坦化。图像兼容模式提供 300/600/1200 DPI，不能提升低分辨率扫描原图的真实细节，最终纸面也受打印机及驱动限制。

页面管理验证了真实鼠标拖动缩略图、多选跨文件移动、复制/删除/旋转及一次撤销；重排保留未删除原页面的书签目标。选择文字后高亮保存为标准批注，可用十二色及自定义色。抓手左键二维平移、空格临时平移和顶部选择/抓手入口，以及 V/H/Esc 切换通过测试。

可见签名只是页面图像；证书签名是独立副本上的 SHA-256 CMS 签名，二者在界面及帮助中明确区分。独立 OpenSSL 验证三种签名样本，包含既有表单及对象流输入，检测单字节篡改和签名后追加内容，另存为保留签名字节。测试证书只在工作目录生成，不安装证书和私钥。

证书验证范围不包含可信时间戳、吊销、DocMDP 权限或后续版本有效性；不声称 PAdES/LTV 合规或法律身份认证。不支持已有签名文档追加签名、加密/XFA 签名或 128 MiB 以上签名。打印机硬件、不同驱动、极端 PDF 和独立 Windows 11 机器仍需实测；测试通过不构成绝对无缺陷保证。
