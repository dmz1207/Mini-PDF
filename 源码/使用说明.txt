Mini PDF 0.6
适用于 64 位 Windows 10 和 Windows 11

启动：双击“Mini PDF.exe”。这是单文件便携版，不需要旁置 DLL 或许可证文件夹。
使用 Windows 自带的 .NET Framework 4.x，不需要安装 Node、Python、Electron、浏览器或额外的 .NET 运行时。

语言
  程序默认英文。菜单 > Language / 语言 可立即切换 English、简体中文，英文排第一。
  切换保留文档和修改；每个新独立窗口默认英文，不创建额外语言配置文件。
  帮助菜单中英文说明排第一、中文说明排第二；F1 打开英文说明。
  系统自带文件和打印对话框跟随 Windows 显示语言。

阅读
  菜单按钮、圆角文档标签、最小化 / 最大化 / 关闭按钮平齐在窗口最顶上一行，没有额外空白标题栏。
  阅读工具栏紧贴下一行；扁平浅色界面，蓝色圆角标签。左上角菜单按钮（F10）展开全部菜单。
  点击“编辑”展开 / 收起编辑工具，侧栏和状态栏默认隐藏。
  Ctrl+O 可多选文件，或拖入多个 PDF；打开新文件会新增标签。
  正文始终只显示当前选中标签的 PDF，不会把不同文档并排显示。
  Ctrl+Tab / Ctrl+Shift+Tab 切换标签；Ctrl+W / Ctrl+F4 关闭当前标签。
  顶部文字和常用图标放大一档；菜单按钮图标更大，点击区域更宽。
  单个和多个文档都使用顶部标题栏内的标签；空白处可拖动窗口，双击最大化或还原。
  在标签文字区域按住鼠标左键即可任意左右拖动，标签跟随鼠标；不松开可连续跨过多个标签并反向拖动。
  拖到标签行两端停留可继续移动到隐藏标签。
  松开鼠标完成拖动，Esc 恢复拖动前的顺序；文件内容、阅读位置和撤销记录保留。
  标签右侧 × 或中键可关闭；有修改会提示保存。
  再次双击 PDF 默认进入已有窗口；Ctrl+Shift+N 新建独立窗口。
  每个标签单独保留页码、缩放、布局、滚动位置和撤销历史。
  阅读工具中拖动选择文字，Ctrl+C 复制。
  中键拖动平移。Ctrl+滚轮缩放。PageUp/PageDown 翻页。
  Ctrl+1 适合页面；Ctrl+2 适合宽度；Ctrl+0 实际大小。
  工具栏可输入精确百分比，例如 87%、123.5%，Enter 确认，范围 1%–6400%。
  下拉框提供常用比例；也可从右键菜单输入精确比例。
  Ctrl+6 自适应单页（整页）；Ctrl+7 自适应双页（铺满宽度）。
  Ctrl+8 书籍；Ctrl+9 当前 PDF 的多页网格总览；不混合不同文档。
  适宽不预留左右灰带；页间距 4 像素，滚动条为窄版原生 Windows 控件。
  缩放百分比保持真实含义，100% 不会伪装成 105%；要铺满请使用适宽。
  视图菜单可切换连续显示。双页和书籍模式按整组翻页。
  网格随缩放自动增加或减少每行页数；双击页面返回单页阅读。
  工具栏“侧栏”或文档左侧 ‹ / › 按钮：收起和打开侧边栏；F12 切换，兼容 F9。
  侧栏边缘箭头采用小浮动按钮，不再占用整条文档宽度；阅读模式隐藏，退出恢复。
  Ctrl+F 查找，Enter/F3 查找下一个。F11 全屏。
  阅读模式按钮或 Ctrl+H：保留窗口标题栏和关闭按钮，隐藏菜单、工具栏、侧栏和状态栏。
  F11 进入真正全屏；Ctrl+L 幻灯片。Esc 或右键菜单退出，恢复原来的界面。
  向左 / 向右旋转视图仅改变阅读方向，不修改 PDF。
  “页面 > 旋转”会修改当前 PDF 页，并进入撤销历史。

修改 PDF
  点击“对象”，单击选择原有文字、图片或图形。
  双击文字直接修改文字内容；会移除原文字对象并写入新文字，非盖白块。
  可选自动字体、微软雅黑、宋体、Arial、Times 和 Courier；自动字体使用英文标准字体和中文系统字体。
  新文字保留原文字块位置；替换字体可能改变字宽，不提供 Word 式整段重排。
  拖动所选对象移动；未旋转页面上拖动右下角调整尺寸。
  也可用“编辑 > 调整所选对象尺寸”输入缩放百分比。
  Delete 删除对象。Ctrl+Z 撤销，Ctrl+Y 重做。
  “文字”：单击页面添加中英文文字，支持多行。
  “图片”：选择图片，在页面上拖出范围，按原比例插入。

双层 PDF
  可读取、选择、复制和搜索扫描图像附带的 OCR 文字层。
  修改识别文字时保留隐藏属性和扫描图像，不会把隐藏文字显示到图像上。
  修改 OCR 层仅改变识别结果，扫描图像上的文字不会随之改变。

批注
  支持高亮、下划线、删除线、手写、矩形、便签。
  标记、手写、便签保存为标准 PDF 批注；矩形和新增文字、图片为页面内容。
  工具 > 下划线 / 删除线。工具栏颜色和线宽作用于下一次绘制。
  对象模式可选择批注；双击便签编辑内容，Delete 删除批注。
  左侧“批注”显示当前页批注。
  PDF 内部已有链接可在阅读模式点击；只允许打开网页和邮件链接。

页面处理
  页面菜单支持旋转、插入空白页、复制、删除、移动、提取和合并。
  提取范围示例：1,3-5,8。按输入顺序提取并去重。
  合并将选择的 PDF 按顺序插入当前页之后。
  导出支持当前页 PNG、全文 TXT；打印支持页码范围和当前页。

保存
  Ctrl+S 保存，Ctrl+Shift+S 另存为。
  使用完整重写和同目录临时文件原子替换；保存失败时不会覆盖原文件。
  保存前重新打开生成的数据并检查页数。
  新增字体保存时做子集化。无需随软件打包系统字体。
  密码保护的 PDF 需要正确密码；编辑受限文档需具有编辑权限的密码。
  已有数字签名在编辑后可能失效，本程序不提供签名验证或签名服务。
  撤销最多 12 步，历史目标上限 64 MiB；至少保留最近一步，大文件可能超过该目标。

当前边界
  尚无 OCR、交互表单填写、数字签名、完整段落重排、可靠的永久信息抹除。
  扫描 PDF 的页面内容是图片，不能直接修改图片里的文字。
  某些 PDF 将文字封装在组合对象内或转为曲线；这些可作为整体移动、缩放、删除，不能逐字编辑。
  默认替换字体，暂不保留原字体的全部排版属性。
  支持多文档标签；暂不提供测量、印章和批注回复。
  高倍缩放按原分辨率分块渲染当前可见区域，显示尺寸和输入百分比保持准确。
  本版已在当前 Windows 10 x64 实测；尚未进行独立 Windows 11 实机测试。

技术与开源
  C# / Windows Forms 使用 Windows 系统已有 .NET Framework，界面通过 Windows 控件绘制。
  PDFium 158.0.8111.0 x64，无 V8、无 XFA。没有 Electron 或 WebView。
  应用源码为 MIT；引擎及依赖许可证已嵌入，可从“帮助 > 开源许可”查看。
  引擎来源：https://github.com/bblanchon/pdfium-binaries/releases/tag/chromium%2F8111
  参考功能：https://github.com/dongfangxy/pdf-looker-pro
  独立实现，未复制 SumatraPDF 或 PDF Looker Pro 的应用代码。
  软件离线运行，无广告、无遥测；不修改默认 PDF 关联。

单文件运行与清理
  程序资源使用 Windows 自带 LZMS 压缩，双击自动解包，无需外部解压软件。
  引擎临时释放到 EXE 旁的“.MiniPDF-runtime-*”子目录，TEMP/TMP 也指向这里。
  正常退出自动清理；异常退出后下次启动清理。不使用系统临时目录存放本程序缓存。
  新建文档默认保存到程序所在目录或用户选择的位置，不会默认保存到运行目录。
  若用户在运行目录里另建了文件，清理会保留用户文件。
  程序所在目录需要允许写入，无需管理员权限或安装。
