# Mini PDF

[English](README.md) | [简体中文](README.zh-CN.md)

**轻量、原生的 Windows PDF 阅读器与编辑器。**

v0.7.1 预览版，单 EXE 约 **2.87 MiB**，面向 Windows 10 / 11 x64。使用系统 Windows Forms、PDFium、Windows 打印及密码学接口，没有 Electron、WebView 或浏览器运行时。默认英文，简体中文排第二，可在菜单中即时切换。

## 本版打磨

- 输入中文或英文姓名立即切换为实时签名预览，导入图片后仍能继续输入姓名。
- 可设定页面上的签名宽度（毫米），预览随大小变化，高度保持比例。文字及绘制签名按放置大小生成较高清晰度图像。
- 确认后可单击放置，也可拖框；放置后自动选中，支持拖动移动、右下角等比例缩放及旋转视图，Esc 取消。
- 新增第三方水印移除工作区，支持勾选文字、图片、整组 Form 对象或图章，先预览，再按内容、样式及位置匹配指定页面范围，整次操作可撤销。

## 已有功能

- 原生打印工作区：预览、打印机属性、页面设置、页码范围、奇偶页、逆序、份数、逐份和驱动支持的双面打印。
- 大小处理包含适合可打印区域、实际大小、仅缩小、自定义精确比例；支持 2/4/6/9/16 页合一、小册子和海报拼接。
- 默认将 PDF 文字和图形以原生矢量方式送到 Windows 打印设备；另有 300/600/1200 DPI 图像打印兼容模式。
- 可见签名支持手绘、输入姓名、导入图片和去白底。文字/图片水印支持透明度、旋转、平铺、页码、范围、预览和撤销。
- 证书签名使用 Windows 密码学接口生成真正的 SHA-256 CMS 签名；分别显示完整性、当前版本覆盖和离线证书信任结果。
- 合并工作区可拖入 PDF 或图片，展开每个文件的页面缩略图，拖动文件组或多选页面跨文件排序，生成新文档。
- 页面管理支持多选、拖动排序、复制、旋转、删除、撤销/重做；整次调整可应用到当前文档并一次撤销。
- 顶部增加选择、抓手、高亮、页面快捷入口；V 回到选择，H 进入抓手，Esc 退出抓手，按住空格临时平移。
- 选中文字后直接高亮，十二种预设颜色及自定义颜色，支持右键菜单。

## 使用方法

将 Mini PDF.exe 放在可写文件夹，双击即可运行。Ctrl+O 打开 PDF，也可拖入文件。多个文件以标签切换，只显示当前选中的文档。

菜单展开按钮、圆角文档标签和窗口最小化/最大化/关闭处于同一顶行，下一行是紧凑工具栏。按住标签的文字区域，用鼠标左键连续拖动到任意位置；Esc 取消本次排序，边缘悬停可滚动更多标签。标签 ×、中键、Ctrl+W 或 Ctrl+F4 关闭；Ctrl+Tab 切换，Ctrl+Shift+N 新建独立窗口。

单页、双页、书籍、连续和多页网格指当前 PDF 内的页面。Ctrl+6 自适应单页，Ctrl+7 双页适宽，Ctrl+2 当前布局适宽。缩放框接受 1%–6400% 的精确小数比例；100% 保持实际比例，适宽用于填满可用宽度。适宽外部灰边约 0–1 像素，双页可能有两像素舍入误差；页间距四像素，原生滚动条在 100% 系统缩放下约十像素。

放大后点击抓手或按 H，用左键任意平移页面。点击选择、按 V 或 Esc 回到文字选择；按住空格可临时平移，松开保持原工具。中键仍可平移。V/H 仅在文档区域获得焦点时作为工具快捷键，不影响输入框正常打字。

Ctrl+H 阅读模式保留系统标题栏和窗口按钮；F11 真全屏，Ctrl+L 幻灯片，Esc 退出。F12/F9 或侧栏按钮切换缩略图、目录和批注面板。Ctrl+F 查找，F3 下一个结果。

无需安装、激活、账号和额外运行时，不含广告或遥测，不修改默认 PDF 关联。运行依赖 Windows 自带 .NET Framework 4.x；不需要 Python、Node.js 或现代 .NET SDK。

## 编辑及页面管理

| 类型 | 功能 |
| --- | --- |
| 文字 | 修改顶层原文字对象，添加中英文和多行文字，选择字体、字号及颜色 |
| 对象 | 移动、缩放、删除文字、图片及图形，插入图片并保留宽高比 |
| 批注 | 高亮、下划线、删除线、手写、便签、批注删除及便签编辑 |
| 页面 | 插入空白页、复制、旋转、删除、提取、排序、合并 |
| 水印 | 文字、图片、透明度、旋转、平铺、位置、范围、页码计数、替换及移除 |
| 导出 | 当前页 PNG、全文 TXT、打印 |
| 保存 | 撤销/重做、重新读取验证、原子替换、字体子集化、保留已有加密 |

展开编辑工具，使用对象工具选择文字后双击修改；Delete 删除，拖动移动；未旋转对象可拖角点缩放，另有百分比缩放命令。文字编辑会移除原文字对象，不以白色矩形遮挡。

选择模式下先拖选文字，再从高亮或右键菜单选择颜色即可标记；Ctrl+Alt+H 使用最近颜色。无文字选择时，高亮工具支持框选区域。标记保存为标准 PDF 批注。

### 页面管理与合并

点击页面或 Ctrl+Shift+P 管理当前文档。文件组可展开为各页缩略图；Ctrl 单击多选，Shift 单击范围选择，按住左键拖动页面排序。复制、旋转、删除以及工作区撤销/重做均可用。应用后整次操作进入当前文档的撤销记录。保留的原页面继续保留其页面目标，指向被删除页面的链接可能失效。

菜单中的合并文件可拖入 PDF、PNG、JPEG 或 BMP。收起时拖动文件组排序，展开后可跨文件移动页面。图片嵌入 A4 页面；合并产生新的未保存文档，原文件保持原样。不支持直接导入 Word/Excel，不将来源文档目录和交互表单结构合成为统一目录或表单。工作区最多 10000 页、20 步内部撤销。

### 双层 PDF

支持扫描图像上的既有 OCR 文字选择、复制、搜索和顶层文字对象编辑，保留文字隐藏/透明属性及原扫描图像。修改识别层不会改变图像中的字。嵌套 Form 内文字可读取及搜索，但不能逐字编辑。软件没有附带 OCR 识别引擎。

## 打印

Ctrl+P 打开 Mini PDF 的原生打印工作区，打印机属性及页面设置使用 Windows/驱动接口。可选全部、当前页、范围如 5,1-3,8、奇偶筛选和逆序；支持份数、逐份、驱动默认双面、单面和可用的长边/短边双面。

页面大小可适合可打印区域、实际大小、仅缩小过大页面或自定义比例；支持自动方向、纵向、横向、驱动纸张、按 PDF 大小选纸、附加页边距、灰度和批注。多页合一、小册子和海报按预览中的纸面顺序输出。小册子可选正反面/仅正面/仅背面和右侧装订，通常搭配横向及短边翻转；手动双面需要按打印机进纸方向翻纸。

默认通过 PDFium 原生 EMF 输出将文字和矢量路径直接发送到打印设备，查看时的缩放不影响打印精度。扫描图像的细节仍取决于源图像，复杂透明内容和驱动可能局部栅格化；纸面清晰度、颜色、最小边距和双面能力也受打印机及驱动限制。

作为图像打印用于兼容有问题的驱动，可选 300、600（默认）、1200 DPI，按块渲染控制内存。既有 AcroForm 外观在内存副本中准备，不修改打开的原文档或表单字段。

## 签名、水印与证书

**可见签名：** 可手绘、输入姓名或导入图片。姓名输入框始终可用，输入后自动切换实时文字预览，中文使用合适的系统字体；图片可去白底。设置页面上的宽度（毫米）后预览同步变化，高度锁定比例。确认后单击页面放置，或拖框设定大小，有鼠标跟随预览。放置后自动选中，拖动移动、拖右下角等比例缩放，右键可输入缩放百分比。Esc 取消放置。它是可编辑页面图像，不代表密码学身份验证，也不自动保存签名图文件或上传。

**水印：** 添加文字或图片、颜色、透明度、角度、居中/顶部/底部、前景/背景、平铺及范围；文字支持 {page}、{pages}，应用可撤销。自动替换仍只识别 Mini PDF 自己标记的水印。

**移除外部水印：** 打开移除水印，选择预览页，筛选并勾选独立文字、图片、整组 Form 对象或图章；显示全部页面对象可查看默认候选列表以外的内容。可以预览移除前后，确认才修改文档。匹配相同水印按内容/样式及页面相对位置和尺寸检查指定范围，避免删除同名但位置、字号不同的正文；另有按钮一键选择 Mini PDF 自带标记的水印。整次删除可撤销。组合对象会整体移除，请核对预览；过大图像或无识别内容的图章可能需要逐页勾选。已经印入扫描图像像素、或与正文混为同一对象的水印，不能作为独立对象完整擦除；此功能不含图像修补，也不保证自动识别所有水印。

**证书数字签名：** 使用 Windows 个人证书库中带私钥的证书，或读取带密码的 PFX/P12。PFX 使用临时密钥，不安装证书、不持久保存私钥。生成独立副本，以 SHA-256 detached CMS 签名，保留已有表单字段。证书审批签名本身不可见，如需手写签名外观请先放置再签署。

验证分别显示签名字节完整性、是否覆盖当前文件及 Windows 离线证书链信任。自签名证书可有完整性但不受信任；签名后追加数据会提示存在未验证的后续内容。签名文档以只读方式打开，另存为保留原字节。

当前范围：128 MiB 以内、未签名且允许编辑的 PDF，暂不支持加密/XFA 文档签名及追加第二个签名。验证支持 detached CMS 和 CAdES detached 的基本完整性，不验证可信时间戳、吊销、DocMDP 权限及后续版本，不提供 PAdES/LTV 完整合规、云签署或法律身份担保。无法支持的签名明确报告，不当作有效。证书查看使用系统窗口。

## 便携运行、体积与限制

单 EXE 使用系统 LZMS 压缩，运行时在 EXE 旁建立隐藏 .MiniPDF-runtime-* 文件夹并将 TEMP/TMP 指向其中，正常退出清理，异常退出由下次启动清理；保护其他活动实例及用户自行放入的文件。程序目录必须可写，自己的文档请保存到运行缓存目录之外。

源码保持可读，删空格不会缩小编译结果；发行包不包含测试工具、Python、调试符号或编译缓存。

这是预览版，文字按对象编辑，替换字体可能改变字宽，不提供段落重排。暂不提供 OCR 引擎、通用交互表单填写、永久抹除、测量、批注回复、Adobe 云工作流或新建链接。大文档及多标签可能超过图像缓存和历史记录的目标内存。

已在 Windows 10 家庭中文版 x64 19045 测试；Windows 11 使用相同 API，仍需独立实机验证；没有 x86/ARM64 发行版。

## 构建与验证

使用系统 .NET Framework C# 编译器，无需另装 SDK：

~~~powershell
powershell -ExecutionPolicy Bypass -File .\源码\build.ps1
~~~

首次构建下载固定 PDFium 158.0.8111.0 x64 并检查 SHA-256。下载、编译和测试均位于项目 work 目录，输出根目录 Mini PDF.exe。

完整测试需要开发用 pypdf、reportlab、pymupdf、cryptography 和 OpenSSL，不随应用分发：

~~~powershell
python .\源码\verify_pdf.py fixtures .\work\tests
python .\源码\verify_features.py fixtures .\work\tests
python .\源码\verify_fixes.py fixtures .\work\tests
powershell -ExecutionPolicy Bypass -File .\源码\build.ps1 -Test
python .\源码\verify_pdf.py verify .\work\tests
python .\源码\verify_features.py verify .\work\tests
python .\源码\verify_fixes.py verify .\work\tests
powershell -ExecutionPolicy Bypass -File .\源码\test-launcher.ps1
~~~

没有外部样本时，程序测试明确跳过相应部分。测试包括原生窗口、真实鼠标/按键消息、保存重读、OCR 图像保留、页面顺序与目标、打印矢量和几何、表单外观、证书完整性及篡改检测、最终 EXE 独立启动和清理。打印使用预览控制器，未发出实体打印任务；具体数量与构建校验见测试记录。通过测试不等于所有 PDF 和驱动都没有问题。
