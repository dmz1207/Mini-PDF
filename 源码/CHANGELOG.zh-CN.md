# 更新日志

## 0.10.1 — 2026-10-23

- 按实际文字选区编辑整段，支持多行、混合字体及跨页。修改、删除、百分比缩放覆盖整个支持的选区，首尾未选中的文字保留原位置。
- F2 或双击文字对象可在文档内编辑，Ctrl+Enter 应用、Esc 取消；点击“窗口编辑”进入独立预览窗口，也可切回并保留草稿。
- 保留未改字符的原始字距和样式；正确显示经过文字矩阵缩放后的实际字号。
- 跨页编辑可逐页预览，页面分隔标记保留页面归属，整次修改一次撤销。
- 修正高分屏输入对话框按钮文字被截断的问题。


## 0.10.0 — 2026-10-23

- 增加 PDF 转 Word DOCX / Excel XLSX，复用系统 ZIP/XML，导出 Unicode、常见对齐表格、数字/编号及可选 Word 图片，不依赖安装 Office。
- 新增标准 AcroForm 工作区，创建、移动、缩放、复制、删除、填写和排序常用字段，支持默认值、选项、标记、撤销及 XFDF 数据导入导出。
- 显示标准字段外观，并修复合并、插入、复制和提取中的字段父子引用、名称及资源，不修改来源文件。
- 转换使用有内存上限的独立进程，支持取消及临时文件清理；修复导出窗口重复释放、高分屏表单属性栏重叠及勾选后应用状态。
- 增强原文字编辑：保留原字体、PDFium 预览、同一行/同样式段落分组、局部自动换行、行距与小数字号。
- 支持范围内保留原文字变换、基线、字距、独立填充/描边透明度、剪裁和标记；改写后复核 Unicode，失败自动回滚。
- 无法确认原字体支持新增字符时要求主动换字体；保留隐藏 OCR 属性，拒绝不支持的竖排、复杂整形、文字剪裁和 ActualText 替代文本。
- 增加可重复的界面/后端及独立 PDF、字体、像素检查和 CI 步骤，不增加生产依赖、不重编 PDFium。
- 下载器补充不完整响应重试和 gzip 解码，保持优先直连、失败后使用现有代理。

## 0.9.0 — 2026-10-22

- 后续验证：保存比较差异改用独立 PDFium 进程逐像素精确复核，保留原始重放证据和 CI 诊断，固定版本 Actions 更新为 Node 24。4,211 路径完整回归检查通过，新增回归为 0；EXE、PDFium 及历史基线不变。[调查记录](CI-Verification.md)。

- 增加跨页拖选、按文档顺序复制、边缘自动滚动和一次撤销的跨页高亮。
- 改善隐藏 OCR 文字命中，分开缩略图与页码的布局空间，覆盖多种系统显示缩放。
- 保留原有与导入字体，合并后规范字体状态，修复四种公开样本在合并、插入、复制后编辑保存崩溃。
- 界面快速渲染仅用于少量纯文字对象，异常图片由后台进程隔离，并关闭工作进程的系统崩溃弹窗。
- 保留合并、插入、复制、提取和页面管理中的图层默认、视图及打印状态；同名但独立的图层不会混淆，页面文字和矢量保持原有形式。
- 在私有导入副本中剔除异常 Contents 数组里缺失或非流引用，保留有效正文和原文件。
- 异常 JPX 原生渲染崩溃时尝试 Windows 内置 PDF 渲染器；该样本颜色仍有偏差，因此明确显示只读兼容预览提示并限制编辑和打印。后台渲染进程有时间及内存上限。
- 增加固定版本、哈希验证的公开测试库工具及 4,211 个 PDF 路径的逐文件实测报告，合并比较差异从 143 降至 3，原生进程失败从 5 降至 1；保留未解决问题和独立证据。
- 保持 PDFium DLL 不变，公开测试文件及开发工具不装入便携 EXE。

## 0.8.0 — 2026-10-21

- 增加按需后台渲染进程，共享不可变输入及图像缓冲区，支持可见页面优先、相邻页预取、取消与异常恢复。
- 普通首屏采用短时渐进渲染，去掉应用层整页像素复制；保留原有渲染质量参数。
- 缓存页面尺寸、建立可见行索引，复用按尺寸及旋转区分的 LRU 缓存，大页只渲染可见分块。
- 合并按来源批量导入并复用图片、字体，再一次恢复准确页序；验证重复页可以独立编辑。
- 侧栏和合并缩略图转为后台；撤销复用只读快照，序列化复用分块缓冲区。
- 重复页使用独立导入批次，避免间接批注随其他副本联动；图标只在启动器保留一份，窗口复用。
- 后续打开先转交已有窗口，不再重复解包；完善后台进程与取消、待投递和缓存图像的释放。
- 合并新增全部文件逐页/分块交错、文件名自然排序、各文件内部倒序及 Ctrl+6～9；保留不等页数、旋转和撤销。
- 拆分并整理输入、渲染、缩略图及文件转交代码，删除无用接口声明。当前仍使用原先经过校验的 PDFium DLL。
- 增加可重复性能工具及并行、像素、生命周期和多文件测试，同步双语说明。

## 0.7.2 — 2026-10-21

- 区分拖动文件名移动整个文件与拖动页面，支持悬停展开、边缘滚动、取消及拖动中布局变化。
- 新增第一份优先、第二份优先、第二份倒序及每 N 页交错，Ctrl+1 恢复原来源归组；Ctrl+1～5 仅在工作区内生效。
- 保留源文件、页面来源及旋转、后续文件组和一次撤销/重做，更新英文及中文帮助。
